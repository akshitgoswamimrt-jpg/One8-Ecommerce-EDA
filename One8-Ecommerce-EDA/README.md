# One8 Sports Analytics – Project Files

This directory contains the core files for the One8 Sports E-Commerce Product Analytics project.

## Project Structure

* `data/` – Cleaned product dataset and supporting CSV files.
* `images/` – Project visualizations and screenshots.
* `notebooks/` – Python-based data cleaning, exploratory data analysis, and business insights.
* `sql/` – Complete SQL analysis and curated portfolio queries.
* `requirements.txt` – Python dependencies required to run the project.
